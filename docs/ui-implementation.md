# 界面实现：安静纸面

状态：0.5.0-dev.1 本地开发版，未发布（2026-11-04 功能补齐后更新）。设计来源为 `docs/design/`（ui-spec、design-tokens、原型）与[设计接入核对](claude-design-implementation-review.md)。本文记录实际实现的行为、与设计的差异和尚未实现的部分。

## 已实现

| 区域 | 行为 |
| --- | --- |
| 壳与布局 | `src/renderer/design-tokens.css` 提供 `--cw-*` 令牌；`layout.ts` 按实际窗口宽度切换宽（≥1280）、标准（960–1279）、紧凑（<960）布局，写在 `.app-shell[data-layout]`。导航顺序为稿件、阅读、发布记录，设置在底部；紧凑时为图标加文字的窄栏。文章 `.markdown` 样式未改动，全局焦点环只作用于可交互元素。 |
| 阅读 | 文章列表按真实发布 / 更新日期分组（今天、昨天、近 7 天、月份），未读用圆点加粗体表示，并为读屏提供“未读 / 有笔记”。正文在单一 `.reader-scroll` 中连续显示，最宽 720px；代码与表格在自身区域横向滚动。说明条区分订阅正文、仅摘要、文字缓存、无内容、已截取和收藏的链接。笔记宽窗口常驻；标准窗口打开笔记时文章列表让位，顶部“文章列表”恢复；紧凑窗口为列表 / 详情切换和底部笔记抽屉。列表面板隐藏时保持挂载，搜索与筛选不丢失。 |
| 订阅 | “添加”菜单包含添加订阅和添加文章链接，均为列表顶部的内联表单，Esc 关闭；添加失败在原位置显示。更新订阅按来源列出失败原因，可只重试失败的来源，已有文章与笔记不受影响。 |
| 稿件 | 首次使用为导入 Markdown / 新建稿件。列表显示标题（最多两行）、首段正文摘要、更新时间、已发布平台与项目。编辑工具栏：收起列表（专注写作）/ 返回、编辑 / 预览（⌘E）、保存状态、插入图片、历史版本、更多（导出 Markdown、归档）和主按钮“准备发布”；正文为空时在标题下方的信息行说明不能发布的原因（与按钮关联），不挤占工具栏；编辑列较窄（标准布局约 960–1100 宽）时，“插入图片”“历史版本”只显示图标并保留名称与提示，工具栏保持一行。标题、元信息与正文共用一个滚动区；标题和正文的高度在文字变化和宽度变化（缩放窗口、收起列表、切换布局）时都会重新计算，不会被截断或出现内部滚动。保存失败时在工具栏下方持续提示并可重试，输入保留。历史版本为右侧抽屉，Esc 关闭并把焦点还给“历史版本”。 |
| 发布准备 | 在稿件区域内替换编辑器，不再是弹窗；进入时焦点在标题，Esc 或“返回编辑”回到编辑器并把焦点还给“准备发布”，处理中阻止返回和切页。掘金按“准备图片 → 复制并打开掘金 → 记录发布链接”分步，复制后明确提示“还不算发布成功”，记录链接按平台校验。X 在右栏显示账号卡、首次配置、短帖和计数；唯一的模态对话框是最终确认（账号与短帖），Esc 只关闭对话框。 |
| X 结果 | 发布结果与辅助操作分开保存（`publishing/xOutcome.ts`）。原生端报告“需核实”的结果显示“结果未确认，请先不要重发”，只保留打开个人主页和人工记录链接；只有 `http.rs` 中对应 4xx 的固定提示（授权失效、额度不足、拒绝访问、请求过频、未接受请求）才显示“X 拒绝了这次请求，内容没有发布”；“X 服务暂时不可用”也可能来自发布前刷新授权时的服务器错误，因此和本机校验、凭证、稿件变化等其他失败一样使用中性的“发布没有完成”。打开个人主页、打开作品或复制链接失败只在下方单独提示，不会清除成功回执或未确认状态，也不会重新出现发布按钮。 |
| 发布记录 | 原“反馈”页更名，数据不变。按平台筛选；列出作品、平台、确认时间与确认方式（人工确认 / 平台回执）；不显示任何评论或阅读数据，空状态说明如何产生第一条记录。 |
| 设置 | 资料与备份、平台连接、应用更新三节。备份 / 恢复使用原生对话框；`restoreFlow.ts` 区分取消、恢复命令失败、恢复完成，以及恢复完成但列表刷新失败。后者显示“资料已恢复，列表暂未刷新”，“重新读取资料”只读取资料，不再次执行恢复；读取成功前，稿件、阅读和发布记录页面不显示旧列表。数据路径在可展开详情中。更新显示当前版本、可用版本和状态；安装失败显示“升级没有完成”、原生错误和“查看升级备份”，不声称当前版本未改动，也不声称已经建立备份——版本核对、下载、签名校验等失败发生在备份之前，是否已有备份以原生说明和“升级备份”文件夹为准；之后任何一次成功检查都会清除旧的检查失败提示。自动检查为开关，回退入口常驻。 |

## 按接入核对处理的差异

- **保存失败另存（P1）**：未提供“另存为 Markdown 副本”。现有 `exportDraft(id)` 只能导出数据库中已保存的版本，不能带走未保存输入；需要新的、接收编辑快照的原生接口后再加入。
- **笔记切换保护（P1）**：保留 `useReadingEditor` 的保存队列。切换文章前先等待保存；失败时留在当前文章、自动展开笔记显示错误与重试。收起笔记、列表让位和断点变化不会卸载编辑状态。
- **渲染与发送保护（P1）**：继续使用 `MarkdownContent`、HTML 净化、公式、Mermaid、作用域锚点和图片按需加载；没有引入原型的简化解析或计时器。发布准备打开前先保存，固定稿件版本，保留防重与账号确认。
- **截断语义（P2）**：“已截取”说明为“内容较长，工作台仅保留前段”；“仅摘要”才说“来源仅提供摘要”。
- **设置契约（P2）**：`backup()` / `restoreBackup()` 仍返回布尔值，因此不显示备份文件名、大小、位置或上次备份时间；恢复确认仍由原生对话框完成。
- **已读状态**：保留显式“标为已读 / 标为未读”，选择文章不会自动改变已读状态。
- **X 文案**：长文默认只带入标题（与 `initialXText()` 一致）；授权中只提供“取消授权”，不重复发起授权请求。
- **紧凑导航宽度**：设计令牌为 64px，实际使用 76px，为 macOS 交通灯留出位置。

## 功能补齐后的界面（0.5.0-dev.1）

以下交互沿用安静纸面的组件与令牌，没有新增顶层页面；详细状态见[功能补齐报告](functional-completion-report.md)。

- 稿件：新建后焦点进入标题并选中“未命名稿件”；保存失败横幅增加“另存当前内容”；“更多”中的导出改为导出当前编辑内容（含图片时为文章包）；归档提示带“撤销”；有未完成准备时主按钮为“继续准备发布”。
- 发布准备：右栏顶部在原稿变化时显示“原稿在准备后修改过，请重新核对”；掘金图片逐张列出结果并可只重试失败项、打开图片文件夹；X 用分段控件切换“网页辅助发布 / 官方 API（实验性）”，没有账号时默认网页辅助。
- 阅读：“添加”菜单增加“导入订阅列表（OPML）”，订阅管理中有导入 / 导出 OPML；文章末尾“下一篇 / 下一篇未读”；列表状态行“整理多篇笔记”进入选择模式，底部条显示已选数量与“生成稿件”。
- 发布记录：页面顶部搜索框；每行可展开详情（本地稿件与发布时版本、记录来源与更正/移除、反馈记录与历史）。
- 设置：备份后显示上次备份回执和“在访达中显示”；恢复先显示备份内容摘要，再在页面内确认；X 连接可单独保存配置；应用更新把“检查”和“升级”状态分行显示。

仍未实现：文章列表键盘方向键漫游、X 授权页重新打开（取消后重新连接即可）、平台自动上传图片与评论读取。

## 验证

- 单元测试（`npm test`）：`tests/ui-states.test.ts` 与 `tests/ui-failure-states.test.ts` 覆盖内容类型、日期分组、布局断点，以及验收发现的状态转换——X 未确认结果在打开主页失败后保留、成功回执在打开 / 复制失败后保留、本机失败不被说成平台拒绝；恢复完成但刷新失败、重试只刷新、取消与失败区分；安装失败的中性提示、后台检查成功清除旧错误。这些测试直接运行组件使用的 reducer 和流程函数。
- 原生 smoke（`tests/tauri-smoke.js`，`npm run smoke:tauri` 或下方命令）：除原有 Markdown 对照、连续阅读、关闭保存等检查外，在真实 WebView 中对生产组件注入故障——只在调试注入脚本内临时替换桥接方法，结束后还原，不发送任何内容、不改动资料——覆盖上述 X（含授权刷新时的服务器错误）、恢复和更新（含备份前的安装失败）序列。
- 响应式回归也在原生 smoke 中：调试专用的 `resize_to` 步骤（仅限 800–1600 × 620–1000）依次把窗口调到 1440、1280、1279、1180、1000、960、959、880、800 宽，检查布局模式与实际宽度一致、页面无横向溢出、编辑工具栏保持一行、长标题和长正文完整显示（不被截断、无内部滚动），并在收起 / 恢复稿件列表后重复；阅读页在笔记展开时切换宽、标准、紧凑布局，检查笔记文字保留、文章列表按布局让位。去掉编辑区随宽度重算高度的逻辑后，该检查会在 1000 宽处失败。
- 修改 smoke 脚本后需重新构建 Tauri 调试程序，因为脚本在编译时嵌入；Linux 上可用 `xvfb-run -a -s "-screen 0 1600x1000x24" node scripts/smoke-tauri.mjs` 运行。
- 其他检查：`npm run typecheck`、`npm run build:frontend`、`npm run build:electron`、`cargo test --manifest-path src-tauri/Cargo.toml --lib --offline`、`npm run test:parity`、`npm run audit:source`。

```sh
npx --no-install tauri build --debug --bundles app --config '{"identifier":"local.contentworkbench.uidesignsmoke"}'
node scripts/smoke-tauri.mjs --packaged "src-tauri/target/debug/bundle/macos/内容工作台 Tauri.app/Contents/MacOS/content-workbench-tauri"
```

浏览器中的模拟接口检查（连续缩放、长标题 / 长正文、列表收起、交互流程）不在仓库中，只作为补充证据。真实 X 账号授权与发帖、掘金最终发布页和线上更新安装仍未验收。
