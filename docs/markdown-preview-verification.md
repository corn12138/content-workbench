# Markdown 预览对照范围

目标：同一份 Markdown 在正文、历史版本、发布窗口中保持内容与排版一致，不增加用户配置。对照样例在 `tests/fixtures/markdown-preview.md`，原生桌面测试在 `tests/tauri-smoke.js`。

## 如何判断一致

| 对照项 | 检查方法 |
| --- | --- |
| 内容和结构 | 比较三个入口的完整 HTML，仅归一化实例锚点与图表内部自动编号 |
| 排版 | 容器固定为 340 px，逐元素比较字体、字号、字重、行高、颜色、对齐、间距和尺寸；尺寸容差小于 0.05 px |
| 流程图和时序图 | 实际解码 SVG 图片，通过 Canvas 比较 PNG 像素输出，并确认不是透明空图 |
| 正常窄窗口 | 按实际布局验证正文与发布窗口没有横向溢出；表格与代码在各自区域滚动 |
| 图片 | 本机图片实际解码，保留说明；外链先显示加载入口，点击内网地址后明确失败且不显示图片 |
| 异常图表 | 错误语法、图内配置指令显示提示并保留源码，不能影响其它图表和正文 |

样例同时覆盖中文、英文、六级标题、重复标题、嵌套列表、任务清单、有序列表起始值、表格对齐、转义字符、硬换行、代码高亮、未知语言、公式、脚注和净化后的 HTML。不同容器宽度的换行本身不属于内容丢失。

## 图表和图片规则

Mermaid 固定配置，本机绘制，不向在线图表服务发送正文。配置指令、外部资源和超过 3 万字符的图表明确提示暂不支持。图表经 SVG 净化后作为独立图片展示，图内链接和回调不执行。

外链图片需要用户点击，Rust 仅下载公网 PNG/JPEG/GIF/WebP，限制跳转、超时、大小及像素数，不携带登录信息。图片只用于当前预览，不代表已随稿保存、离线可用或上传至平台；需要随稿保留时使用插入图片或文章目录导入。普通 HTML 的自定义脚本、样式、iframe、内嵌 SVG 不作为可执行内容展示。

## 外部平台边界

- 掘金：本轮访问其编辑器后进入登录页，未修改或发布平台草稿。缺少真实平台渲染结果，因此没有跨平台逐像素一致的证据。
- X：本版发布纯文本短帖，发送内容以右侧短帖编辑框为准；左侧 Markdown 是原稿参考。[官方创建帖子接口](https://docs.x.com/x-api/posts/create-post)接收文本与媒体等字段。真实授权和发帖待用户配置开发者应用后单独验收。
- 本机的同宽布局和图表像素检查不等于全页截图逐像素检查，也不能穷举所有 Markdown 方言或系统字体。最终发文前仍应核对平台预览。

旧版正式下载、用户原始资料和 Electron 回退继续保留。本轮使用独立测试资料，不发送真实帖子。

## 本轮验证记录

2026-10-29，本机 macOS 原生桌面两阶段测试通过，三个预览入口的同宽排版与图表像素对照通过。Node 测试 22 项通过，Rust 离线测试 40 项通过；网络专项测试不纳入离线计数。源码路径检查覆盖 1031 个文件，暂存内容、完整历史与展开的源码快照均通过敏感信息扫描，依赖审计无已知漏洞。

本轮原生测试环境未提供剪贴板权限，因此复制按钮的系统剪贴板验证标记为跳过；不把这一项算作通过。完整状态保存在本机生成的 `artifacts/tauri-comparison/native-smoke.json`，该目录不随源码提交。远端 CI 状态以 PR 检查为准。
