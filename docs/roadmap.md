# 路线图

本地工作流保持免费开源，以实际使用反馈安排版本，不承诺尚未验证的平台能力和日期。

1. 0.1 开发者预览：文字写作、版本、掘金辅助发布、阅读笔记与备份恢复，优先修复资料和保存问题。
2. 0.2 开发版：图片随稿保存、资源导出、完整资料备份和按需 RSS/Atom 阅读；先完成桌面验收，再发布。
3. 逐个平台验证授权、费用、真实发布、评论和指标；未通过验证的功能不标为正式支持。
4. 扩大桌面支持：Windows、Linux、Intel Mac 实机验收，签名公证、升级和自动更新。

第一阶段不建设 AI、插件商店、支付系统或复杂账号体系。后续可评估赞助、可选托管同步、团队服务和技术支持；本地导出与备份不设付费门槛。
