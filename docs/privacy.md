# 隐私与资料

应用没有工具账号系统、云同步或行为追踪。稿件、图片、历史版本、订阅内容、阅读笔记和发布记录存放在本机 SQLite 中。只有用户在 X 预览中确认发布后，才向 X 发送短帖正文。

数据库与导出的 `.cwb` / 旧 JSON 备份未加密。操作系统账户安全和文件存放位置会影响资料安全；分享备份等于分享其中的正文与记录。

点击添加或更新订阅时，Rust 直接向填写的 RSS/Atom 地址发起请求；源站会看到网络地址与应用标识。应用不发送稿件、笔记、平台凭据或浏览器 Cookie，不读取系统代理。仅支持公网 HTTP/HTTPS 的标准端口，不能订阅内网或需要登录的来源。

点击打开文章或平台按钮时，应用才请求系统浏览器打开对应链接，随后由该网站处理访问。复制正文会把文字写入系统剪贴板。预览不自动加载远程图片，不执行原始 HTML。

文件导入、导出及备份使用原生选择器。恢复前创建本地恢复副本；删除阅读记录或归档稿件不会清理此前导出的备份。自行删除旧备份前先确认无需恢复。

首次检测到旧 Electron 资料时，会验证并复制至 Tauri 独立目录，原资料保留。没有后台任务在应用退出后继续访问平台。

问题反馈请移除个人文章、账号、文件路径和数据库内容。仓库测试使用虚构数据；依赖许可证中保留的上游作者联系方式属于授权声明。

X 连接使用系统浏览器与 OAuth 2.0 PKCE；Rust 直接访问 X 官方 API。授权时会读取账号资料，发帖前可能刷新令牌。令牌仅存 macOS 钥匙串，按资料目录隔离，不进入页面、SQLite、备份或日志。X 网络请求遵循系统/进程代理配置，禁用 HTTP 重定向；RSS 的独立客户端仍不读取代理。

发布防重日志单独保存在 `publish-journal.sqlite`，仅含请求身份哈希和成功后的公开作品链接，不含正文或令牌。它不随内容备份导入或导出，避免恢复旧备份后重发。换机不会带走防重日志，发布前需要核对已有作品。断开会先删除本机凭证，再尝试撤销平台令牌；网络失败会提示到 X 设置撤销。
