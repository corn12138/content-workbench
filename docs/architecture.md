# 架构与数据边界

Tauri 2 承载桌面窗口，React 管理界面，Rust 管理业务校验、SQLite、文件选择、剪贴板和系统浏览器入口。

| 模块 | 职责 |
| --- | --- |
| `src/renderer` | 稿件、反馈、阅读与设置；编辑保存及退出协调 |
| `src/shared` | TypeScript 业务契约 |
| `src-tauri/src/store` | Rust 业务规则、版本与备份完整性检查 |
| `src-tauri/src` | 原生命令、受限文件操作、迁移与窗口生命周期 |
| `src/core` 与 `src/desktop` | Electron 回退内核和桌面层 |

前端通过明确的业务命令操作资料。原生窗口限制导航和新窗口；预览禁用原始 HTML，外链只允许普通 HTTP/HTTPS。数据库使用事务，恢复前验证格式与关联关系，并保留恢复副本。

Electron 与 Tauri 使用独立目录。Tauri 0.2 仍可导入旧 JSON，但默认导出完整 `.cwb`；Electron 保持旧版文字功能，拒绝 schema 2。升级前保留独立 v1 数据库。迁移对旧库做只读在线备份，在临时目录验证导出与恢复往返，再安装到尚不存在的目标。已有目标资料不会被覆盖。

关闭窗口先要求前端提交未保存的修改，原生端等待完成；无响应时提供恢复选择。调试冒烟钩子不进入 release 构建，数据和钥匙串探针必须显式启用 `probes` feature。

图片以内容哈希索引并存入 SQLite BLOB，与正文和订阅共用事务。完整备份是带版本、大小和 SHA-256 清单的 ZIP；恢复只读白名单条目到内存，不把归档路径解压到文件系统。历史版本引用的图片和已取消订阅的缓存内容继续保留。

RSS 通过 Rust 在资料锁之外获取，限制 DNS、重定向、超时及字节数，再以短事务去重入库；当前仅按需刷新。已取消订阅不会被旧响应重新启用，恢复操作递增代次并丢弃旧更新结果。前端展示纯文本摘要，不执行源站 HTML 或加载远程图片。

平台自动发布、后台任务与同步尚未实现。新增能力仍需保持本地写作可独立使用。
