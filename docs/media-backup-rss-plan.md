# 图片、完整备份与订阅阅读

在现有三个主入口中补齐本地资料闭环，不增加账号或技术配置。

1. 导入 Markdown 自动复制其目录及子目录中的 PNG、JPEG、GIF、WebP 图片；拒绝目录外路径、越界符号链接、SVG 和超限图片。外链保持引用但不自动下载。
2. 图片按内容哈希保存在 SQLite 的资源表，正文使用稳定相对引用。原图变化不会修改已保存版本；历史版本引用的资源继续保留。编辑器提供原生选择器插入图片。
3. 有图片的文章导出为包含 Markdown 与 assets 的 ZIP，无图片仍导出 Markdown。完整备份为单个 .cwb 文件，包含 v1 文字数据、图片、订阅及阅读关联、版本和 SHA-256 清单。
4. 恢复先验证全部文件与引用，不解压任意路径；先写完整恢复副本，再在同一 SQLite 事务内替换资料。继续接受旧 JSON 文字备份。schema 2 升级前留存 schema 1 数据库；旧 Electron 不直接打开新版库。
5. 阅读页增加添加订阅、更新与取消订阅。RSS/Atom 文章直接进入原有阅读列表，展示来源摘要；用户笔记与已读状态不被刷新覆盖，取消订阅保留已收集文章。
6. 首版订阅按需刷新，退出后不后台采集。网络请求有超时、大小与重定向上限，拒绝内网地址并固定已验证 DNS 结果；远端 HTML 不执行、不自动加载图片。

图片和正文共用数据库事务，避免恢复时数据库与文件目录只成功一半。ZIP 只作为交换格式，内部路径不决定落盘位置。网络更新不占用资料锁，不阻塞本地写作或退出；恢复后丢弃旧更新结果。

验证覆盖：路径与图片限制、原图删除后的预览、历史图片稳定性、带资源导出重导入、备份往返与损坏拒绝、旧库升级与旧备份、RSS/Atom 解析与地址限制、重复更新保留笔记、取消订阅和恢复后的陈旧请求，以及桌面主流程。
