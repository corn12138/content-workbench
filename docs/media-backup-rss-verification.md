# 0.2 开发版验收

平台：macOS Apple Silicon。版本：0.2.0-dev.1；公开 0.1.0 发行版不变。

## 自动验证

- TypeScript 类型检查、前端构建及 13 项 Node 测试通过；包含 RSS 发布时间跨时区排序。
- Rust 29 项离线测试通过，覆盖图片导入、路径越界、原图移除后的持久化、历史资源、完整恢复、旧 JSON、升级前副本、损坏拒绝、失败回滚、RSS/Atom、去重及取消订阅。
- 单独启用的网络检查成功读取 Rust 官方 RSS。网络检查不作为 CI 离线测试的硬依赖。
- Electron / Rust 14 项对照通过，旧 Electron 拒绝打开 schema 2；原目录仍可用于回退。
- 原生冒烟两阶段通过：存储图片显示、订阅纯文本显示、内网地址拒绝、完整备份往返、剪贴板、人工发布记录、窄窗口、切页保存、关闭与退出时的待保存编辑。

## 原生手动验收

全部使用独立临时目录与合成图文；未向任何平台发布内容。

- 原生选择器导入 Markdown，同目录图片自动保存；“插入图片”写入正文并自动保存，重复图片只存一份。
- 移走原图后，恢复后的两处图片引用仍正常预览；导出 ZIP 包含完整 article.md 和去重资源，资源哈希一致。
- 真实添加 Rust Blog，显示源站内容；手动更新不重复入库，取消订阅保留离线内容和笔记。
- 设置中导出单个 .cwb；校验清单、图片、订阅、笔记及已读状态全部存在。
- 新增测试稿件后恢复 .cwb，当前资料正确替换；自动生成的完整恢复副本包含恢复前新增稿件、图片和订阅。
- 安装形态的构建可直接启动；阅读页按发布时间显示新内容优先。

## 数据与发布边界

- `.cwb` 包含已保存在应用中的资源，不自动下载远程图片；平台发布仍需自行上传图片。
- 仅按需刷新 RSS；不在后台轮询，不抓取源站没有提供的完整正文，不需要账号或 AI。
- 依赖审计未发现已知漏洞；Rust 锁文件仍有 5 个非 macOS 目标依赖警告，分别为 proc-macro-error、zbus_names、zvariant、zvariant_derive、glib。
- 源码含更新后的 457 项依赖声明。原样保留上游许可证的空白，不改写授权文件。
- macOS 构建使用本地 ad-hoc 签名；没有 Developer ID、公证或自动更新。Windows、Linux、Intel Mac 未验收。
