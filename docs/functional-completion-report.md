## 剩余限制与未验收项

- **X 官方 API**：真实开发者应用、授权回调、令牌刷新/撤销、真实发帖、公开数据读取均未用真实账号验收（用户没有开发者应用）。验收步骤见[平台能力核验](platform-capabilities.md#真实账号验收清单需要用户自己的-x-开发者应用)。
- **X 网页辅助**：实际 X 撰写页的打开与预填行为未在真实浏览器中验证（smoke 中注入了打开操作，未打开浏览器）。
- **掘金**：最终发布页样式与图片上传未验证；无自动数据接口。
- **系统对话框**：另存、备份、OPML 导入导出、恢复选文件均由原生对话框完成，自动化测试通过注入桥接或直接调用同一 Rust 逻辑覆盖，没有点击真实对话框。
- **线上更新**：未进行线上检查与真实安装（开发版不检查线上更新，也未发布新版本）。
- 剪贴板：本次原生 smoke 中剪贴板可用并已测试，结束后由测试框架恢复原内容。
- 平台范围：只在 macOS Apple Silicon 验证。

## 几分钟试用顺序

1. 打开预览应用，在「稿件」选“本地优先应用的备份设计”，点“更多 → 导出（含图片）”保存一份文章包；新建稿件，确认光标已在标题。
2. 选“一条短帖的发布准备”，点“继续准备发布”：X 已选“网页辅助发布”且短帖保留；点“复制并打开 X”（会打开浏览器，不会自动发帖）；返回编辑改一句正文，再回来看到“请重新核对”。
3. 在「阅读」打开“用 SQLite 事务保护本地资料”，读到末尾点“下一篇”；在列表状态行点“整理多篇笔记”，选两篇有笔记的文章生成稿件。也可从“添加 → 导入订阅列表（OPML）”试导入（需联网）。
4. 在「发布记录」展开示例作品：打开稿件、查看发布时版本、记录一次反馈（留空的项会显示“未知”）、更正链接。
5. 在「设置」备份资料，看回执与“在访达中显示”；点“恢复备份”选刚才的文件，先看摘要，再决定恢复或取消。
6. 退出再打开，阅读回到上次的文章，发布准备仍在。
