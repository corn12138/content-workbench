# 订阅排版预览版

> 0.5.0-dev.1 补充：订阅管理中可导入 / 导出 OPML（导入前预检重复、无效、本机或内网地址与 50 个上限，确认后最多 3 个并发添加，失败的来源可单独重试；拒绝含 DOCTYPE 的文件，不展开任何实体）。应用记住上次阅读的文章和大致位置（本机视图偏好，不进入内容备份）；文章末尾提供“下一篇 / 下一篇未读”，只在当前搜索、来源和筛选结果内前进，打开文章不会自动标为已读。“有笔记”列表可“整理多篇笔记”，按列表顺序生成一篇带标题、来源链接和原笔记的稿件，同一组笔记重复整理会打开已有稿件。

状态：0.5.0-dev.1 本地开发预览，未发布到 Releases 或自动更新通道。正式版仍为 0.4.0。

## 操作

在「阅读」添加 RSS / Atom 地址，选择文章即可阅读。已有订阅点击「更新订阅」后，可获取来源仍提供的正文排版；只保留在旧缓存中的文章继续显示原有文字。

标题、段落、列表、代码换行与缩进、表格和网页链接在一个连续阅读区中直接显示，不再需要展开；宽代码和表格在各自区域内横向滚动。图片需点击「加载这张图片」；笔记在宽窗口常驻右侧，默认窗口打开笔记时文章列表让位，最小窗口为底部抽屉。

正文上方的说明条区分：「订阅正文」（来源提供的正文，不保证等于网页全文）、「仅摘要」（来源只提供摘要；RSS `<description>` / Atom `<summary>` 中的 HTML 若有 600 字以上文字，或有标题、代码、表格、图片、引用或三段以上，按订阅正文处理）、「文字缓存」（早期保存的纯文字）、「无内容」与「已截取」（工作台超过保存上限时仅保留前段）。「打开原文」始终保留。本版不会抓取任意网页全文，也不会自动订阅 X 时间线或任意掘金作者。

## 数据与安全边界

原有纯文字摘要继续用于列表和搜索；可选的正文独立记录格式、来源类型和是否截断。HTML 作为非执行文本保存在本机，显示时先解析、净化，再构造 React 节点，不直接注入 HTML。脚本、事件、嵌入页面和任意样式被移除；相对网址按文章地址解析，不能引用本机资源。图片沿用受限公网下载，不携带平台账号凭证。

单条正文最多保存 100,000 个 Unicode 字符，超出会明确标注；订阅总缓存仍受 96 MB 限制。过于复杂的排版不进入递归渲染，并提示打开原文。纯文字 Atom 内容不会被误当成 Markdown 或 HTML。

## 与旧版兼容

首次打开 schema 3 数据库时，会先写出独立的 `before-reading-upgrade-<随机标识>.sqlite`，完成同步后再升级为 schema 4。备份失败会停止升级。旧版应用拒绝新格式，避免错误写入。

新版本导出的 `.cwb` 使用格式 3；新版能读取旧格式 2 和旧 JSON 文字备份。0.4.0 无法恢复格式 3。回退前导出新版完整备份、退出所有版本并保留整个新版资料目录；在独立空目录中使用升级前的 schema 3 副本，命名为 `workbench.sqlite`，再交给 0.4.0 使用。不要覆盖新版库或混用 WAL / SHM 文件。升级后的改动仍留在新版目录，两边不会自动合并。

Electron 继续使用自己的原资料目录，不能直接打开 Tauri 新库。旧发行包和原正式资料不被本地预览替换。

## 验证方式

`npm test` 覆盖 HTML 净化、结构保留、相对链接、锚点、复杂内容降级和跨来源搜索。`cargo test --manifest-path src-tauri/Cargo.toml --lib` 覆盖 RSS / Atom 解析、长度限制、旧字段缺省、备份往返与升级前副本。

原生桌面验收使用独立测试资料与 `tests/fixtures/reading-feed.xml`：检查真实 WebView 中的代码缩进、表格、链接、图片待加载、展开收起、窄窗口和笔记保存。它不代表任意来源网站的像素复刻。真实联网来源与独立试验数据只存放在被忽略的 `artifacts/`，不进入公开仓库或发行包。

X 真实授权与发帖仍依赖尚未创建的开发者应用，配置见[第一次连接 X](x-first-connection.md)。掘金仍提供辅助发布，自动送入草稿与最终发布回执是独立待验收能力。本版没有新增平台发帖。
